# Rectify12 — Full Windows 12 UI Transformation

Rectify12 is the complete visual and structural overhaul of Project Rebirth to deliver a true Windows 12 experience, inspired by Rectify11 principles but redesigned for the next generation.

## Core Principles
- Consistent Fluent 2 language (16–28 px corner radii, acrylic surfaces, soft shadows)
- Touch-first with 40 px+ targets
- Floating, unanchored shell elements
- Zero mandatory telemetry, local-first AI
- Modular, composable UI components

## Transformed Components
- **Shell**: Modern centered floating Taskbar + full Start Menu + Desktop with icons & widgets
- **OOBE / Installer**: Multi-step privacy-first setup
- **Apps**: Settings, File Explorer, Copilot, Widgets, Notifications, Lock Screen, Snap Layouts, Photos, Terminal
- **Themes**: Rectify12 (default), Sunset, Dark Carbon

All components live under `src/UI_Components/` and follow the new theme resources.
